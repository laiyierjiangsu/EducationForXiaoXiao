# AI 的“聪明”从哪里来？

面向初中生的网页讲座，共 30 个场景。内容依据同目录的 SLIDE_OUTLINE.md。项目直接位于 `share/ai`，由外层 EducationForXiaoXiao 仓库统一管理。

## 本地运行

需要 Node.js 22.13 或更高版本。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。构建使用 `npm run build`，数学检查使用 `npm test`。

## 讲解操作

- 右方向键、空格或“下一步”：逐步揭晓，到末步后进入下一屏。
- 左方向键或“上一步”：回退步骤，再回到上一屏，保留该屏的讲解进度。
- “自动演示本屏”：每 3.5 秒推进一次，到本屏末步停止，可随时暂停。
- “重播”：恢复本屏第一步和交互初始值；“显示完整”直达末步。
- 目录可跳到任意场景；章节导航可跳到章节起点。
- 讲者备注含讲法、概念边界与来源。快捷键 N 切换备注，M 打开目录。
- 参数页可拖动 a、b，切换柱状图与坐标图；误差曲线、权重、小网络支持调整数值。
- 浏览器支持时使用“全屏”。小屏布局自动重排；减少动态效果的系统设置会关闭过渡。

## 现场前需要准备

官网页是切换到真实 Codex 演示的提示页，不是假操作。请提前确定学校名称、官网和近期日期范围，核实两条活动原文，再预演语音与工具操作。失败备用素材需标注“预演”。

围棋、王者荣耀局面采用教学示意；数学数据、候选概率与通知均明确标注为自编。当前未加入真实比赛视频。

## 内容编辑

- `app/scenes.ts`：标题、旁白步骤、讲者备注和来源。
- `app/visuals.tsx`：各屏图表及计算呈现。
- `app/math.ts`：实际驱动画面的数学计算。
- `app/page.tsx`：讲者控制、目录与逐步播放。
- `app/globals.css`：投影、移动布局和动画。

## 安全与验证记录

此讲座只展示固定教学材料与内存中的数字参数，不收集学生信息、不提供上传或登录表单、不使用 AI 密钥，也不实际控制电脑。数字输入有范围和整数检查；内容由 React 转义，不使用 HTML 注入、动态代码执行或用户地址导航。外链是固定 HTTPS 来源并隔离新窗口。无应用数据库、令牌、密码或持久化存储；认证和访问范围由托管平台负责。日志不记录学生或讲者输入。

使用官方 Sites 模板与 npm 配置的企业镜像；版本固定在 package.json 与 package-lock.json。模板依赖审计发现问题后更新对应直接依赖及配套插件；最终审计结果见交付说明。未新增数据服务或第三方素材请求。

数学测试覆盖人数模型、平方误差、误差曲线、非线性网络、奖励与概率，以及场景目录。另执行 TypeScript 类型检查、构建与所有分镜的静态渲染检查。没有进行浏览器交互或投影设备实测，现场仍需试讲检查可读性。

安全复核卡：入口为按钮和有限数值；边界为浏览器与固定外链；无敏感数据存储、加密或应用授权流程；无文件/IPC/原生内存操作；依赖由锁文件固定。后续如加入上传、真实 AI 调用或远程控制，需重新确认输入验证、凭据、权限、日志、保留期限和安全测试。
