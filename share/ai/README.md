# AI 的“聪明”从哪里来？

面向初中生的网页讲座，共 35 页、97 个展示状态。完整内容与讲者资料见 [SLIDE_OUTLINE.md](SLIDE_OUTLINE.md)。

## 内容结构

1. **看见能力**：围棋 → 团队配合 → 查询学校官网，引出表示、训练、生成和行动。
2. **学会规律**：用校园活动人数讲清规则、参数、误差、训练和新情况验证，再联系游戏反馈。
3. **生成语言**：文字的数字表示 → 计算组合 → 从文字练习 → 联系上下文 → 生成后续。
4. **使用工具**：指令、执行、反馈与查证，回看开场的官网任务。
5. **独立判断**：核实合成内容、保护隐私、遵守规则，以及继续学习与创造。

每页围绕一个问题，画面按步骤变化；数学计算保留中间过程。章节过渡用深色背景，讲解页用浅底深字。投屏不显示讲稿和常驻操作栏。

## 本地运行

需要 Node.js 22.13 或更高版本。

```sh
npm ci
npm run dev:local
```

打开 **http://127.0.0.1:3000**。Windows 本地入口使用 Node/Vite，不依赖 Workers 运行时。锁文件下载地址已改为公共 npm 源，版本和完整性校验保持不变。

原托管入口保留为 `npm run dev`、`npm run build`。本地构建使用 `npx vite build --config vite.local.config.ts`。

## 演示操作

- **→ / 空格 / PageDown**：下一步；本页结束后进入下一页。
- **← / PageUp**：上一步；回到前页时保留进度。
- **右侧“目录” / M**：展开目录，默认收起；按章节查找，或搜索标题、内容和页码。
- **点页面标题**：从该页第一步开始；展开标题右侧的步骤列表，可直达任意一步。当前页面与步骤会高亮。
- 选中后目录自动收起；**Esc**、关闭按钮或点击目录外侧也可收起。
- **R**：重播当前页；**End**：展示当前页完整内容。
- **F**：切换全屏；若浏览器不支持，可使用浏览器全屏功能。

算例按预设步骤改变参数，保证数值、图形和结论同步。首页和过渡页只需一次推进。

## 现场准备

提前确定学校名称、官网与近期日期范围，核实两条活动原文，再预演真实工具操作。课件中的官网流程仅作教学说明，不模拟已经成功完成查询。备用材料标明“预演”。

棋盘、游戏局面、数学数据与通知均为明确标注的教学示意。讲者备注与参考资料保存在大纲和 `app/scenes.ts`，不会出现在投屏画面。

## 开发与检查

- `app/scenes.ts`：顺序、章节、标题、每步短结论与讲者资料。
- `app/visuals.tsx`：所有教学图示与计算状态。
- `app/math.ts`：数学计算。
- `app/page.tsx`：键盘导航、目录与画面布局。
- `app/slide-navigator.tsx`：右侧抽屉目录、搜索和精确步骤定位。
- `app/globals.css`：投屏与小屏排版。

`npm test` 检查数学及目录数据；`npm run lint` 检查代码；`npx tsc --noEmit` 检查类型。重设计版使用浏览器遍历 35 页、97 个展示状态，检查 1280×720 投屏布局，并抽查图示截图与目录开合。

这是固定教学材料的本地演示，不采集学生信息，也不直接调用 AI 或操作学校官网。
