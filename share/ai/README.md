# AI 的“聪明”从哪里来？

从一条直线到 Transformer。面向初中生，由讲者通过数学与现实例子深入讲解的网页演讲。

2026-09-08 内容重构：**42 页，50 个可查看状态，仅 3 页包含手动演示状态**。白底、深蓝文字、蓝绿强调色；首页即全场地图，末页回到主题。每页完整呈现主题、算例或图表、解释和结论，没有自动播放、逐条入场或空白章节过渡。

完整逐页大纲与讲者资料见 [SLIDE_OUTLINE.md](SLIDE_OUTLINE.md)。

## 本地运行

需要 Node.js 22.13 或更高版本，已安装依赖时无需再次安装。

```sh
npm ci
npm run dev:local
```

打开 **http://127.0.0.1:3000**。本地入口使用 Node/Vite，不依赖 Workers 运行时，适用于 Windows 本地演示。原托管入口 `npm run dev`、`npm run build` 保留，未新增依赖。

## 操作

- **← / →**：直接翻页，每次进入都能看到完整讲解内容。
- **空格 / PageDown**：长页面先向下滚动，到底后下一页；**PageUp** 反向操作。
- **Home / End**：第一页 / 最后一页。
- **M / 右侧目录**：按章节查找、搜索标题、解释、结论或页码，选中后关闭。
- **F**：全屏；浏览器不支持时使用浏览器全屏功能。
- **第 07、10、29 页**：点击图表下方数字切换演示状态；**R** 重置当前演示。翻页不强制走完演示。
- 目录只为上述三页显示状态入口，其余页面直接跳转。
- 小屏纵向排列图表与解释，允许正常滚动，不裁切内容。没有后台计时器或自动动画。

## 现场准备

1. 选定学校名称、官网、近期范围，预先核实两条活动原文；第 04 页切换到真实 AI 工具演示。
2. 第 23 页打开 [TensorFlow Playground](https://playground.tensorflow.org/)，第 30 页打开 [LLM Visualization](https://bbycroft.net/llm/)，均保留在新标签页。
3. Playground 只用原始 x₁、x₂，避免启用平方特征改变线性对照实验。反复据 Test loss 调模型时，这份数据实际承担验证集作用。
4. 外部站点需联网。讲前预演，备用材料标注“预演”；课件不伪造操作成功。

销量、棋盘、游戏情境、向量、概率、成本及通知均注明教学示意。数学计算由同一模块提供；MSE 单位为杯²。预测时只能使用决策时可获得的信息，真实数据不能混入事后信息。

## 实现与验证

- `app/scenes.ts`：42 页主题、三项解释、结论、演示状态、来源、讲者备注。
- `app/visuals.tsx`：图表、公式、结构图和手算展示。
- `app/math.ts`：销量模型、损失、梯度、微型网络与稳定 Softmax。
- `app/page.tsx` / `app/slide-navigator.tsx`：演讲布局、键盘与目录。
- `app/globals.css`：浅色主题、投屏布局、小屏与减少动态效果规则。

```sh
npm test
npx tsc --noEmit
npm run build
```

算例测试覆盖联合损失与配方的一致性、有限差分检验梯度、逐次更新、非线性小网络、Softmax 数值稳定性与注意力计算。`tests/render.tsx` 可由已安装的 esbuild 编译后执行，覆盖全部 42 页 / 50 个画面状态、首页以及每页的目录入口。

本轮验证为计算、类型、服务端渲染、页面 HTTP 响应和生产构建；未进行浏览器截图或实际投影仪视觉验收。

## 数据与安全边界

课件使用固定教学数据，只有本地页码、目录搜索和预设状态；不采集学生信息，不直接调用 AI、不代替用户操作官网。文本通过 React 转义，搜索限长，状态索引有范围检查；外部资料仅使用固定 HTTPS 链接，新标签页使用 `noopener noreferrer`。未新增账号、数据库、密钥、埋点、文件上传或第三方依赖，既有托管访问策略保持不变。
